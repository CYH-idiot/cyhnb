# 07 猜单词游戏（Hangman）

> 难度：★★★☆☆（综合）| 预计用时：1 小时

## 项目说明
从词库随机选单词，逐字母猜，猜错 6 次失败。词库支持从 `words.txt` 文件加载。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| 文件读取 | `with open()` + 逐行处理 |
| `os.path.exists()` | 文件存在性检查（备用词库兜底） |
| 集合 `set` | 记录猜过的字母，自动去重 |
| 生成器表达式 | `" ".join(letter if ... else "_" for letter in word)` |
| `all()` | 判断单词是否全部猜出 |

## 运行方法
```bash
python hangman.py
```
