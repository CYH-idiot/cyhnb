# 08 通讯录管理

> 难度：★★★☆☆（综合）| 预计用时：1.5 小时

## 项目说明
完整的管理系统：联系人增删改查 + 数据持久化（JSON 文件存储，重启不丢失）。这是 8 个项目中最接近"真实软件"的一个。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| 嵌套字典 | `contacts = {"姓名": {"phone": ..., "email": ...}}` |
| `json` 模块 | `json.load()` / `json.dump()` 序列化 |
| 文件持久化 | 每次修改即保存，防止数据丢失 |
| 完整 CRUD | 增（Create）删（Delete）改（Update）查（Read） |
| 容错处理 | 文件损坏时降级为空字典 |

## 运行方法
```bash
python contacts.py
```
运行后会在当前目录生成 `contacts.json` 数据文件。

## 升级挑战
1. 增加"分组"字段（家人/同事/朋友），支持按组筛选
2. 手机号格式校验（11 位、以 1 开头）
3. 支持搜索关键字（模糊匹配姓名）
4. 导出为 CSV，用 Excel 打开
