# 04 石头剪刀布

> 难度：★★☆☆☆（进阶）| 预计用时：45 分钟

## 项目说明
你和电脑对战石头剪刀布，三局两胜制，带计分。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| `random.choice()` | 从列表随机取一个元素 |
| 字典映射 | `WIN_RULES` 用查表代替复杂 if |
| 列表 `list` | 存储合法选项 |
| 函数拆分 | `play_round()` 单独负责胜负判断 |
| 计分循环 | `while` 直到一方先得 2 分 |

## 运行方法
```bash
python rock_paper_scissors.py
```

## 升级挑战
1. 改为五局三胜，并显示每局的出招记录
2. 加入"电脑策略"：分析你的出招习惯反制
3. 统计胜率并显示
