# 05 密码生成器

> 难度：★★☆☆☆（进阶）| 预计用时：30 分钟

## 项目说明
按指定长度和字符类型组合，随机生成高强度密码。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| `string` 模块 | `ascii_lowercase`、`digits` 等字符集 |
| 列表推导式 | `[random.choice(pool) for _ in range(n)]` |
| `random.shuffle()` | 原地打乱列表顺序 |
| 函数参数设计 | 布尔参数控制是否包含某类字符 |

## 运行方法
```bash
python password_generator.py
```

## 升级挑战
1. 一次生成 10 个密码让你挑选
2. 给密码强度打分（长度、字符种类、是否含重复）
3. 支持"可读性密码"：用单词+数字组合（如 Cat2024!）
