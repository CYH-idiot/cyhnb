# 06 待办清单

> 难度：★★☆☆☆（进阶）| 预计用时：50 分钟

## 项目说明
命令行菜单式待办管理：添加、查看、标记完成、删除任务。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| 列表 + 字典 | `tasks = [{"text": ..., "done": ...}]` |
| `enumerate()` | 遍历列表同时拿到序号 |
| 菜单模式 | `while True` + 数字分支（CLI 程序经典结构） |
| `pop()` | 按下标删除元素 |
| 异常处理 | `try/except` 防止序号越界崩溃 |

## 运行方法
```bash
python todo_list.py
```

## 升级挑战
1. 任务增加"截止日期"字段
2. 数据持久化：退出后任务不丢失（参考 08 项目的 JSON 存储）
3. 按完成/未完成分组显示
4. 任务排序：未完成的排前面
