# 01 猜数字游戏

> 难度：★☆☆☆☆（入门）| 预计用时：30 分钟

## 项目说明
电脑随机生成一个 1~100 的整数，你不断猜测，程序提示"大了/小了"，直到猜中。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| `random.randint()` | 生成随机整数 |
| `input()` + `int()` | 接收输入并转换类型 |
| `if / elif / else` | 条件分支 |
| `while True` + `break` | 无限循环与退出 |
| `isdigit()` | 字符串是否全为数字 |

## 运行方法
```bash
python guess_number.py
```
