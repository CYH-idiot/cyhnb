# 03 温度转换器

> 难度：★☆☆☆☆（入门）| 预计用时：25 分钟

## 项目说明
摄氏、华氏、开尔文三种温度单位互相换算。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| 函数封装 | 把换算公式写成独立函数 |
| f-string | `f"{value:.2f}"` 格式化并保留小数 |
| `while` + `break` | 菜单循环 |
| `strip()` | 去除输入首尾空格 |

## 运行方法
```bash
python temperature.py
```

## 升级挑战
1. 增加"摄氏度与开尔文"反向换算入口
2. 批量转换：一次输入多个温度（用逗号分隔）
3. 把换算历史写入文件 temperature.log
