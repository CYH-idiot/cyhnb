# 02 简易计算器

> 难度：★☆☆☆☆（入门）| 预计用时：40 分钟

## 项目说明
输入两个数字和一个运算符（+ - * /），程序输出计算结果，支持连续计算。

## 涉及知识点
| 知识点 | 说明 |
|---|---|
| `def` / `return` | 定义和调用函数 |
| 字典 `dict` | 用运算符当 key 绑定函数 |
| `try / except` | 捕获 `ValueError`、`ZeroDivisionError` |
| `float()` | 支持小数的类型转换 |
| `if __name__ == "__main__"` | 模块导入保护 |

## 运行方法
```bash
python calculator.py
```

## 升级挑战
1. 增加 `%` 取余、`**` 幂运算
2. 支持连续运算（比如 2 + 3 * 4 按优先级算）
3. 记录历史运算结果，输入 `history` 查看
4. 用 `round()` 控制小数位数
