## 🗺️ 全套学习流程

### 第 0 步：环境准备（10 分钟）
1. 已安装 Python 3（本机已有 Python 3.14）✅
2. 检查是否安装成功：打开终端输入 `python --version`
3. 建议安装 VS Code 编辑器 + Python 插件（已有 VS Code 直接用）
4. 每个项目文件夹内独立运行，互不干扰

### 第 1 步：先打基础（2~3 天）
动手写项目前，先过一遍这些语法（会认会用即可，不用背）：
- `print()` 输出、`input()` 输入、变量与类型（int/float/str/bool）
- `if / elif / else`、`for`、`while`、`break` / `continue`
- 函数 `def` / `return`、参数与返回值
- 列表 `list`、字典 `dict`、字符串常用方法
- `import` 导入模块（`random`、`json`、`os`）

> 免费资料：菜鸟教程 Python3、廖雪峰 Python 教程、B 站搜索"Python 基础教程"。

### 第 2 步：按顺序完成 8 个项目（2~3 周）
**铁律：先自己写，再对照参考代码。** 每个项目的正确做法：

1. **读项目说明**（每个文件夹里的 README.md）
2. **关掉代码文件**，自己新建一个 `.py` 从头写
3. **写不出来时**再看参考代码的对应部分（比如"循环怎么写"）
4. **运行、调试、改错**（见第 3 步）
5. **完成基础版后做"升级挑战"**（每个 README 底部都列了）

### 第 3 步：学会调试（贯穿始终）
写代码 50% 的时间在改 bug，学会这些就不慌：
- **看报错信息**：最后一行是错误类型（`NameError`=变量名拼错、`TypeError`=类型不对、`IndentationError`=缩进问题）
- **print 大法**：不确定哪里出问题就在关键位置 `print(变量)` 看值
- **注释掉一部分代码**：逐步缩小问题范围
- 报错不怕，**读懂它**就是进步

### 第 4 步：完成标准（如何判断过关）
每个项目能独立完成以下动作即算过关：
- 不看参考代码能写出来 ✅
- 能说出每一行代码的作用 ✅
- 至少完成 1 个"升级挑战" ✅
- 代码里有自己的注释 ✅

### 第 5 步：进阶方向（8 个项目完成后）
按兴趣选一条路继续：
- **爬虫方向**：requests + BeautifulSoup 抓取网页数据 → 练手：爬豆瓣电影 Top250
- **自动化方向**：文件批量整理、Excel 处理（openpyxl）、邮件自动发送
- **数据分析**：pandas + matplotlib 做图表分析 → 练手：分析自己一个月消费记录
- **Web 开发**：Flask 做个人网站 → 练手：把通讯录做成网页版
- **游戏方向**：pygame 做小游戏

> 推荐参考：GitHub 上 `Jack-Cherish/PythonPark`（学习路线文章）、`python-mini-projects`（100+ 小项目合集）

## 📌 学习建议

1. **每天 30 分钟**，比周末 5 小时效果好
2. **不要复制粘贴**代码 —— 手敲才能形成记忆
3. **每完成一个项目就 git 提交一次**，记录成长轨迹：
   ```bash
   git add .
   git commit -m "完成项目 01：猜数字游戏"
   git push
   ```
4. 卡住超过 30 分钟再看答案，不丢人
5. 把"升级挑战"当成正式任务做，这才是真正拉开差距的地方
